# Final Reflection
## CCM101 - The Enterprise Cloud Architect

This laboratory activity helped me understand how cloud applications can be deployed and managed using virtualization and containerization.

I learned how to install and configure Ubuntu Server in VirtualBox, install Docker, and use Docker Compose to run WordPress and MariaDB. I also learned how containers communicate through a private network and how persistent volumes help protect application and database data.

Another important part of this activity was configuring the UFW firewall, creating a Bash automation script, and scheduling automatic database backups using Cron. These tasks helped me understand the importance of system security, automation, and regular maintenance.

I also experienced some challenges during the configuration process, especially when managing services and setting up the environment. By following the commands and checking the outputs, I was able to understand and resolve the issues step by step.

Overall, this activity improved my knowledge of Linux server administration, Docker, database management, and cloud infrastructure. These skills will be useful in managing and deploying applications in real-world environments.
